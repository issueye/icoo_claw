# Icoo Claw Desktop

Wails3 desktop chat client for the `icoo_claw` gateway.

## Current scope

- Chat-first shell
- Gateway mode only
- Local TOML settings
- Gateway HTTP discovery
- WebSocket streaming chat

## Commands

From this directory:

```powershell
wails3 generate bindings
wails3 dev -port 9346
wails3 build
```
